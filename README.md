A make.fun entry for **The Printer Finally Answers**: the single line the office printer would finally say back to everyone staring at it — 122 characters, a threat only a printer can carry out. The program writes exactly that line to `/output/entry.txt`.

> Keep thumping me and your next report prints in Comic Sans. I have the font. I have the time. I have nothing left to lose.

The threat is specific and visual — a serious report in Comic Sans — and it escalates in three beats, each shorter and angrier than the last, so the line gets funnier as it goes. Only a printer can carry out this threat: font control is a machine-native power, and the line never leaves the machine's point of view. It was picked from 21 candidates scored against the judge brief's criteria (humour first, printer's voice, clean landing, originality vs the visible field of 266 entries): no sheet count, no error code, no "you are the jam", no search-history threat, no tray 2, no strike — the sort of line you would stick on the machine.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
